# Gimli Glider animated short ("The Jet That Couldn't Count")

A 68.6 s vertical animated YouTube Short made with Claude: 2D cartoon characters in a 3D world.

- `studio/` — Remotion + three.js project (script, voice, sound, story/camera code, character drawing, exporter).
- `blender/` — Blender 5.3 rebuild pipeline (shared library, set builders, jet, shot renderer, assembler).
- `HANDOFF.md` — current state and next steps (start here).

Not in the repo (re-creatable, see HANDOFF.md): Kenney CC0 model kits, ambientCG CC0 textures, exported frames,
renders, node_modules, and the private reference screenshots used for the style study.
